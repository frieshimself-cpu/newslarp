# newslarp

A single-page, made-up Lithuanian news article: **"Atrasta nauja begemotų rūšis: naktį švytinti Genny nustebino mokslininkus"** — the discovery of *Choeropsis nyctolumen*, a pygmy hippo species whose skin glows in moonlight, and Genny, the first of its kind to be described.

Open `index.html` in any browser. It's all in one file (fonts load from Google Fonts). Includes:

- News-portal layout: masthead, section nav, breaking-news ticker, sidebar with "most read" and "latest"
- Hand-drawn SVG illustration of Genny at night, plus a camera-trap frame
- Fact box, pull quote, tags and related stories
- Working extras: copy link / share, text size A−/A+, comment form and likes

"Gintaro Žinios", the journalist and the scientists are all invented.
